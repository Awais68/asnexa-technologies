# AsNexa Technologies

Public-facing frontend for AsNexa Technologies, built with Next.js App Router, TypeScript, Tailwind CSS and Lucide icons.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production checks

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Scope and integration notes

- This repository currently implements the public-facing frontend only.
- The contact form currently prepares a prefilled email in the visitor's email application. It does not submit to an API or store personal information.
- The contact recipient `hello@asnexatech.com` is a provisional placeholder and must be verified or replaced before launch.
- No authentication, CRM, analytics, database or booking integration is configured.
- Portfolio content intentionally avoids fabricated clients, testimonials, metrics and case studies.
- Organization structured data does not assert a physical address or unverified contact details.

## Routes

- `/` Home
- `/services` Services overview
- `/services/[slug]` Individual service pages
- `/industries` Industries
- `/about` About
- `/work` Project approach
- `/contact` Contact
- `/robots.txt` and `/sitemap.xml` generated by Next.js
